# shuhang-f.github.io

Personal website for Sean Feng — live at [shuhang-f.github.io](https://shuhang-f.github.io).

## Stack

Vanilla HTML, CSS, and JavaScript. No frameworks, no build step. Deployed via GitHub Pages.

## Structure

```
index.html        # single-page site
css/style.css     # all styles
js/main.js        # nav behavior, scroll animations
images/           # profile photo
favicon.ico
```

## Local dev

```bash
open index.html
```

Or use any static file server:

```bash
npx serve .
```
